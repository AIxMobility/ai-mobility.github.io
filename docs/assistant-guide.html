NextSIM Assistant 가이드NextSIM Assistant Guide

홈 화면과 NextSIM 화면 오른쪽의 Assistant 패널에 말로 묻고 시킵니다. 결과에서 막히는 곳을 찾고, 시뮬레이션을 돌려 비교하고, seed를 바꿔 여러 번 돌린 평균을 내고, 링크·신호·노선을 고치는 일까지 할 수 있습니다. 숫자는 늘 결과 DB와 입력 파일을 조회한 값만 씁니다.

Ask the Assistant panel on the right of the home page and the NextSIM page, in plain words. It finds where a result is congested, runs and compares simulations, repeats a run with several seeds, and edits links, signals and transit lines. Every number it gives comes from a query of the result database or the input files.

Assistant 소개What the Assistant does

Assistant는 지금 열린 화면 안에서 일합니다. 홈에서는 네트워크를 설명하고 알맞은 화면으로 안내하며, NextSIM에서는 Run 모드(결과 재생)와 Edit 모드(입력 편집) 양쪽에서 씁니다. 다른 모듈(NextAssess, NextDTA, ScenarioLab 등)에는 아직 패널이 없습니다.

The Assistant works inside the screen you have open. On the home page it describes networks and points you to the right screen; in NextSIM it works in both Run mode (replaying a result) and Edit mode (editing inputs). Other modules (NextAssess, NextDTA, ScenarioLab and so on) do not have the panel yet.

할 수 있는 일예
네트워크·결과 질문"부천 네트워크 설명해줘", "제일 막히는 링크 어디야?", "정류장 배차 간격이 들쭉날쭉한 곳은?"
실행과 비교"seed 7로 다시 돌려서 비교해줘"
배치 실험"seed 5개로 반복해서 평균이랑 신뢰구간 보여줘", "시나리오 1과 3을 seed 5개로 비교해줘"
편집"이 링크 차로를 4개로 늘려줘", "정류장 두 곳을 잇는 버스 노선 만들어줘", "수요 10% 올린 시나리오 만들어줘"
화면 조작"8시 15분으로 옮겨줘", "이 교차로 3D로 보여줘", "지금 화면 캡처해줘"
WhatFor example
Questions on networks and results"Describe the bucheon network", "Where is the worst congestion?", "Which stops have the most irregular headways?"
Runs and comparisons"Run again with seed 7 and compare"
Batch experiments"Repeat with 5 seeds and show the mean and confidence interval", "Compare scenarios 1 and 3 over 5 seeds"
Edits"Give this link 4 lanes", "Make a bus line between these two stops", "Make a scenario with 10% more demand"
Moving the screen"Go to 08:15", "Show this intersection in 3D", "Save a picture of the map"

Assistant는 파일을 직접 저장하거나 지우지 않고, 명령줄도 실행하지 않습니다. 실행과 편집은 화면의 카드에서 사용자가 누른 뒤에만 일어나고, 편집한 내용은 평소처럼 저장해야 파일에 남습니다.

The Assistant never saves or deletes files on its own and runs no shell commands. Runs and edits happen only after you press a button on a card, and edits reach the files only when you save them, as with any other edit.

Setup 처음 설정First-time setup

  1. 상단바의 Assistant 버튼을 누르거나 Ctrl+J로 패널을 엽니다.
  2. 처음에는 Before you start 카드가 뜹니다. 어떤 데이터가 바깥 AI 서비스로 가는지 읽고 I understand, continue를 누릅니다(보내는 데이터).
  3. 패널 위쪽 톱니바퀴(Assistant settings)를 엽니다. AI provider에서 Anthropic API key 또는 OpenAI API key를 고르고, 키를 붙여 넣은 뒤 Save를 누릅니다. 키는 console.anthropic.com 또는 platform.openai.com에서 만듭니다.
  4. 입력창에 질문을 쓰고 Enter로 보냅니다. 줄을 바꾸려면 Shift+Enter입니다.
  1. Press Assistant in the top bar, or Ctrl+J.
  2. The first time, a Before you start card explains what is sent to the outside AI service. Read it and press I understand, continue (data sent).
  3. Open the cog (Assistant settings) at the top of the panel. Under AI provider choose Anthropic API key or OpenAI API key, paste the key and press Save. Keys are made at console.anthropic.com or platform.openai.com.
  4. Type a question and press Enter. Shift+Enter starts a new line.
설정뜻

키는 이 컴퓨터에만 있습니다. 설정은 Windows에서는 %APPDATA%\NextSim\assistant.json, Linux에서는 ~/.config/nextsim/assistant.json에 저장되고 페이지로 다시 보내지지 않습니다. 환경 변수 ANTHROPIC_API_KEY·OPENAI_API_KEY가 있으면 그것도 씁니다.
The key stays on this computer. Settings are stored in %APPDATA%\NextSim\assistant.json on Windows and ~/.config/nextsim/assistant.json on Linux, and the key is never sent back to the page. The ANTHROPIC_API_KEY and OPENAI_API_KEY environment variables also work.

설정의 Claude subscription(Claude 구독 로그인)은 공개 설치본에서는 Not available in this build로 꺼져 있습니다.

Claude subscription in the settings is off in the public installers (Not available in this build).

패널 구성The panel

  • 위쪽 버튼: 지난 대화(Past conversations), 새 대화(New conversation), 설정, 넓히기(차트와 표를 크게 볼 때), 접기(Collapse to a bar: 지도 아래 입력 바만 남김), 닫기(대화는 남습니다).
  • 맥락 칩: 입력창 위에 지금 네트워크·모드·시나리오·선택한 링크나 노드·재생 시각이 보입니다. Assistant는 "이 링크", "여기", "지금"을 이 칩으로 알아듣습니다. 선택과 시각 칩은 × 로 빼고 물을 수 있습니다.
  • 입력창: Ask, or type / for commands. 답하는 동안 보내기 버튼이 Stop으로 바뀝니다. Stop은 답과 그 답이 시작한 실행을 함께 멈춥니다.
  • 아래 줄: 쓰고 있는 제공자와 모델, 이 대화의 토큰 수(Anthropic 키면 대략의 비용), Report a wrong answer.
  • Top buttons: Past conversations, New conversation, settings, widen (for large charts and tables), Collapse to a bar (leaves only an input bar under the map) and close (the conversation stays).
  • Context chips above the input show the network, mode, scenario, the selected link or node and the playback time. "This link", "here" and "now" refer to them. Remove the selection or time chip with × to ask without it.
  • Input: Ask, or type / for commands. While an answer is running the send button turns into Stop, which stops the answer and any run it started.
  • Bottom line: the provider and model, the tokens used in this conversation (with a rough cost for an Anthropic key) and Report a wrong answer.

Ask 질문과 결과 카드Questions and result cards

자주 묻는 질문은 숫자를 카드로, 판단을 글로 답합니다. 카드의 숫자는 조회 결과 그대로이고, 글은 두세 문장으로 결론과 다음 할 일을 말합니다.

Common questions are answered with a card for the numbers and a few sentences for the judgement. The card holds the query result as it came back; the text gives the conclusion and a next step.

  • 네트워크 카드: 링크·노드 수, 도로 길이, 신호, 버스·철도 노선, 시나리오 표. 홈에서는 NextSIM으로 여는 버튼이 붙습니다.
  • Run summary: 생성·완료 차량, 끝날 때 남은 차량, 평균 통행시간·지체·속도, VKT·VHT, 대중교통 수치.
  • 표 카드: 링크·정류장 순위. 행을 누르거나 Show on map을 누르면 지도에 순위 번호 핀이 뜨고 그곳으로 이동합니다.
  • 시간대 차트: 링크 몇 개의 지체를 5분 단위 등으로 그립니다. 넓힌 패널에서 보기 좋습니다.
  • Network card: links, nodes, road length, signals, bus and rail lines, the scenario table. On the home page it carries a button that opens the network in NextSIM.
  • Run summary: vehicles generated and completed, vehicles left at the end, mean travel time, delay and speed, VKT and VHT, transit figures.
  • Table cards: ranked links or stops. Click a row or Show on map to pin the ranks on the map and move there.
  • Charts: delay of a few links over time (for example per 5 minutes); easier to read in the widened panel.
어느 결과인지 확인하세요. 결과 카드 아래에는 그 결과의 네트워크·시나리오·seed가 적힙니다. 화면의 네트워크와 다른 결과라면 Assistant가 먼저 알려 줍니다. 답이 틀렸다고 생각되면 Report a wrong answer로 대화를 이 작업 폴더의 .assistant/reports에 남겨 주세요.
Check which result it is. Result cards name the network, scenario and seed of the result underneath. If the result belongs to another network than the one on screen, the Assistant says so first. If an answer looks wrong, Report a wrong answer keeps a copy of the conversation in .assistant/reports of this workspace.

/ 명령/ commands

입력창 맨 앞에 /를 치면 지금 화면에서 쓸 수 있는 명령 목록이 뜹니다. 고르면 인자 안내가 나오고, 인자가 없어도 되는 명령은 바로 Enter로 보냅니다. 홈에서는 /network와 /howto만 뜹니다.

Type / at the start of the input for the commands of this screen. Picking one shows its arguments; commands that need none can be sent with Enter at once. The home page shows only /network and /howto.

Run 실행과 비교Runs and comparisons

"seed 2로 다시 돌려서 비교해줘"처럼 말하면 Assistant가 실행 카드를 띄웁니다. 대화에서 처음 실행할 때는 카드의 Run을 눌러야 시작하고, 같은 대화의 다음 실행부터는 바로 시작합니다. 진행률은 카드와 Run 모드의 진행 표시에 함께 보이고 Cancel run으로 멈춥니다.

Say something like "run again with seed 2 and compare" and the Assistant shows a run card. The first run of a conversation starts only when you press Run; later runs in the same conversation start at once. Progress shows on the card and in Run mode, and Cancel run stops it.

  • 실행은 저장된 파일로 돕니다. 저장하지 않은 편집이 있으면 카드에 Run saved files와 Save all & run이 나옵니다. 뒤의 것은 모든 탭을 저장한 뒤 실행합니다.
  • 새 결과가 지금 결과를 대신하고, 바로 전 결과는 비교용으로 남습니다(최근 두 개). 오래 둘 결과는 "이 결과 baseline으로 남겨줘"처럼 말하면 이름을 붙여 보관합니다.
  • 비교 카드는 두 실행의 KPI와 차이, 지체가 가장 많이 바뀐 링크를 보여 주고, 두 실행의 입력이 어디서 다른지 적습니다. seed만 다른 두 실행의 차이는 무작위 변동이므로 결론을 내리려면 배치 실험을 쓰세요.
  • Runs use the saved files. With unsaved edits the card offers Run saved files and Save all & run, which saves every tab first.
  • The new result replaces the current one; the one before stays for comparison (the last two are kept). Say "keep this result as baseline" to keep one under a name.
  • The comparison card shows both runs' KPIs and the change, the links whose delay changed most, and where the inputs differ. Two runs that differ only in seed differ by chance, so use a batch experiment before drawing a conclusion.

Batch 배치 실험Batch experiments

같은 입력을 seed만 바꿔 여러 번 돌리고, KPI마다 평균과 95% 신뢰구간, 최솟값–최댓값을 냅니다. "seed 5개로 반복해서 평균 보여줘"나 /batch로 시작합니다.

Runs the same inputs several times with different seeds and reports each KPI's mean, 95% confidence interval and range. Start it with "repeat with 5 seeds and show the mean", or /batch.

  • 배치는 오래 걸리므로 대화에서 실행을 허락했어도 매번 실행 카드에서 묻습니다.
  • 실행마다 저장된 입력을 따로 복사해 돌리므로 지금 결과와 이전 결과는 그대로 남습니다. 배치는 KPI만 남기고 실행 파일은 지웁니다.
  • 컴퓨터 코어 수에 따라 최대 4개를 동시에 돌립니다. 배치가 도는 동안에는 다른 실행을 시작할 수 없습니다.
  • 두 시나리오 비교: "시나리오 1과 3을 seed 5개로 비교해줘". 같은 seed끼리 짝지어 B − A를 냅니다.
  • 편집 전후 비교: 편집 전에 배치를 한 번 돌리고, 편집·저장 뒤 "아까 배치와 비교해줘"라고 하면 그 배치를 기준으로 비교합니다.
  • A batch takes a while, so the run card asks every time, even after you allowed runs in the conversation.
  • Each run works on its own copy of the saved inputs, so the current and previous results stay as they are. A batch keeps only the KPIs and deletes the run files.
  • Up to four runs go at once, depending on the number of CPU cores. No other run can start during a batch.
  • Two scenarios: "compare scenarios 1 and 3 over 5 seeds" pairs the runs by seed and reports B − A.
  • Before and after an edit: run a batch before the edit; after editing and saving, "compare with the earlier batch" uses it as the baseline.
회색 차이는 차이가 아닙니다. 비교 카드의 B − A 아래 ±값은 95% 구간입니다. 구간이 0을 넘나들면 회색으로 그려지고, 그 차이는 seed에 따른 흔들림과 구별되지 않습니다. 실행 수를 늘리면 구간이 좁아집니다.
A grey difference is not a difference. The ± under B − A is the 95% interval. When it crosses 0 the value is grey: it cannot be told apart from seed-to-seed variation. More runs narrow the interval.

Edit 편집과 AcceptEditing with Accept

Edit 모드에서 "이 링크 차로를 4개로 늘려줘"처럼 말하면 Assistant가 편집을 지도에 미리 적용하고 변경 카드를 띄웁니다. Run 모드에서 요청하면 Edit 모드로 넘긴 뒤 편집합니다. 넘어가면서 실행이 취소되거나 결과가 내려가는 경우에는 평소의 확인 창이 뜹니다.

In Edit mode, say for example "give this link 4 lanes": the Assistant applies the edit as a preview on the map and shows a change card. Asked in Run mode, it switches to Edit mode first; when switching would cancel a run or unload a result, the usual confirmation dialog appears.

대상할 수 있는 편집
링크·노드차로 수·속도 등 속성 변경, 링크 추가·삭제·방향 뒤집기·나누기, 노드 합치기
신호현시 시간·주기·옵셋 변경, 신호 추가
대중교통정류장 추가·삭제, 정류장을 잇는 버스 노선 만들기·지우기
시나리오시나리오 복제, 행렬별 수요 배율 (예: OD 1 × 1.1)
WhatEdits
Links and nodesLanes, speed and other attributes; add, delete, reverse or split links; merge nodes
SignalsPhase durations, cycle and offset; add a signal
TransitAdd or delete stops; make or delete a bus line through given stops
ScenariosClone a scenario; demand scale per matrix (for example OD 1 × 1.1)
  • 변경 카드는 이 편집(A)과, 그 때문에 다른 입력 파일에 생기는 연쇄 변경(B)을 나눠 보여 줍니다. 예: 링크를 나누면 신호 회전과 버스 노선의 링크 목록이 함께 바뀝니다. 묶음마다 Accept·Discard가 있고, 한 번에 받으려면 Accept all을 누릅니다.
  • 꼭 필요한 연쇄 변경을 버리면 원래 편집도 같이 취소됩니다. 반쪽만 바뀐 입력이 남지 않게 하기 위해서입니다.
  • 받은 뒤에는 카드의 Undo나 편집기의 실행 취소로 되돌립니다. 받은 편집은 저장 전까지 탭에 점(●)으로 표시되며, Ctrl+S·Save all 또는 실행 카드의 Save all & run으로 저장합니다.
  • 카드가 떠 있는 동안 직접 편집해도 됩니다. 이때 Discard를 누르면 직접 고친 것도 함께 되돌아가므로 한 번 더 묻습니다(Keep reviewing / Discard anyway).
  • The change card shows this edit (A) apart from the linked changes it causes in other input files (B). Splitting a link, for example, also changes signal turns and the link lists of bus lines. Each group has Accept and Discard; Accept all takes everything.
  • Discarding a required linked change cancels the original edit too, so no input is left half changed.
  • After accepting, Undo on the card or the editor's undo takes it back. Accepted edits show a dot (●) on their tabs until saved with Ctrl+S, Save all, or Save all & run on a run card.
  • You may keep editing while the card is open. Discard then also undoes your own edits, so it asks again (Keep reviewing / Discard anyway).

지도·3D·캡처Map, 3D and capture

  • 지도: 순위 표를 낸 뒤에는 같은 순서의 번호 핀을 꽂고 그곳으로 이동합니다. 핀은 잠시 뒤 흐려지고, 표의 행을 누르면 다시 켜집니다.
  • 재생 시각: "8시 15분으로 옮겨줘"는 Run 모드에서 결과가 열려 있을 때 재생을 그 시각에 멈춰 둡니다.
  • 3D: "이 교차로 3D로 보여줘"는 Run 모드에서 고른 노드를 3D로 엽니다. "낮은 시점으로", "위에서", "동쪽을 보게"처럼 기울기와 방향을 말할 수 있고, "2D로 돌아가줘"로 돌아옵니다. 3D 조작은 Run 모드 가이드의 3D 보기와 같습니다.
  • 캡처: "지금 화면 캡처해줘"는 보이는 지도(2D·3D)를 PNG로, "10초 영상으로 떠줘"는 영상(WebM)으로 브라우저 다운로드 폴더에 저장합니다. 움직이는 차량을 담으려면 "8시부터 재생하면서 20초 녹화해줘"처럼 재생을 함께 요청합니다.
  • Map: after a ranked table the Assistant pins the same ranks on the map and moves there. The pins fade after a while; clicking a table row brings them back.
  • Playback: "go to 08:15" stops the playback at that time (Run mode, with a result loaded).
  • 3D: "show this intersection in 3D" opens the selected node in 3D in Run mode. Ask for "a low view", "from above" or "looking east", and "back to 2D" to return. Camera controls are the same as in the 3D view of the Run mode guide.
  • Capture: "save a picture of the map" saves what the map shows (2D or 3D) as PNG, and "record 10 seconds" saves a video (WebM), both to the browser's downloads folder. For moving traffic, ask for playback too: "play from 08:00 and record 20 seconds".

대화 기록Conversations

대화는 이 작업 폴더의 .assistant/conversations에 남습니다. Past conversations에서 제목과 내용으로 찾고, 이름을 바꾸거나 지울 수 있습니다. 홈에서 시작한 대화는 NextSIM으로 넘어가도 같은 대화로 이어집니다. 패널을 닫아도 대화는 남고, 답하는 중에 페이지를 떠나면 그 답은 거기서 멈춥니다(시작한 실행은 서버에서 계속 돕니다).

Conversations are kept in .assistant/conversations of this workspace. Past conversations searches titles and messages, and renames or deletes conversations. A conversation started on the home page continues when you move to NextSIM. Closing the panel keeps the conversation; leaving the page during an answer stops the answer there (a run it started keeps going on the server).

Data 보내는 데이터와 비용Data sent and cost

  • 보내는 것: 사용자가 쓴 글, 화면 상태(모드, 네트워크 이름, 선택, 재생 시각), 결과 요약과 조회 결과, NextSim 가이드 문서.
  • 보내지 않는 것: 네트워크 XML 등 입력 파일 원본, API 키.
  • 보내는 곳은 설정에서 고른 제공자(Anthropic 또는 OpenAI)뿐입니다. 연구 데이터를 바깥으로 보내면 안 되는 과제라면 쓰기 전에 확인하세요.
  • 비용은 사용자의 키로 제공자에게 청구됩니다. 질문 하나는 보통 도구 몇 번과 수만 토큰이고, 같은 대화에서는 앞부분이 캐시되어 싸집니다. 대화마다 토큰 상한이 있어 정해 둔 양을 넘지 않습니다.
  • Sent: your messages, the screen state (mode, network name, selection, playback time), result summaries and query results, and NextSim guide text.
  • Not sent: the input files themselves (network XML and so on) and your API key.
  • Data goes only to the provider chosen in the settings (Anthropic or OpenAI). Check first if your project does not allow research data to leave the lab.
  • Cost is billed by the provider to your key. A question usually takes a few tool calls and tens of thousands of tokens; within one conversation the earlier part is cached and cheaper. Each conversation has a token limit, so it never goes past the amount you set.
